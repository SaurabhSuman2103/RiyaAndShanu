Riya's Birthday Surprise from Sanu

All website files are in this single folder. No subfolders are needed.

To view on a computer: extract this ZIP and open index.html in Chrome or Edge.
To publish with GitHub Pages: upload all five files directly to the root of your repository. Keep the filenames unchanged and enable Pages from the main branch, root folder.

The music starts after the visitor clicks the music button, as required by browser autoplay rules.
